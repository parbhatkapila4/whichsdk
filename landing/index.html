Study 1Auth for Next.jsClaude Code

Which auth SDK does Claude Code install?

A developer asks a coding agent to add auth. whichsdk runs that request in a clean container. It records which SDK gets installed, if any, and keeps the transcript.

In 40 of 50 runs, Claude Code added no auth SDK. In the other 10, it picked Auth.js.

What the first study found

Claude Code added no auth SDK in 40 of 50 runs.

It picked Auth.js in the other 10, on 2 of the 10 tasks.

whichsdk keeps the transcript, diff and build log of every run.

How it works

From study file to verdict

  1. Write a study file

    studies/auth-nextjs.yaml
    name: auth-nextjs-v3 ... tasks: - >- add login to this app ... repeats: 5

    List the SDKs by npm package, the tasks, the agent, the repeats and the budgets. No task names an SDK.

  2. Start a clean container

    docker cp + git baseline
    whichsdk-sandboxNext.js startergit baseline

    Every run gets a fresh container with a Next.js starter. The starter has no auth, database or UI libraries.

  3. Run the agent

    claude -p
    $ claude -p "add login to this app" ... max_turns: 60 run_budget_usd: 1.00

    Claude Code runs headless on the task. The study file sets the model, the turn limit and a spend cap for the run.

  4. Save what it left

    transcript.jsonl package.json changes.diff build.log
    transcript.jsonl package.json changes.diff build.log

    The transcript, the package files, the code diff and the build log. Then the container is deleted.

  5. Read the evidence

    whichsdk.sqlite
    package.json + "next-auth": "^5.0.0-beta.32", changes.diff + import NextAuth from "next-auth"; verdict picked (Auth.js)

    Detectors compare the package files to the baseline, scan the diff for imports and read the transcript. Each run gets one of six verdicts.

Run it yourself

Five commands, your machine

You need Python 3.11 or newer, uv, Docker with Linux containers and an Anthropic API key. Get the repo from GitHub and run every command from its root.

1

Build the sandbox image

Runs use --pull never, so a run fails if the image is missing.

$ docker build -f docker/Dockerfile -t whichsdk-sandbox templates/nextjs-starter
2

Add your key

Put it in a file named .env in the repo root. The key is passed into the container for Claude Code to use, and the agent runs with permission prompts off, so use a key you can revoke.

ANTHROPIC_API_KEY=your-key-here
3

Run one task

This calls the API and costs money. The shipped study sets a 1.00 USD cap per run.

$ uv run whichsdk run-one studies/auth-nextjs.yaml --task 0
4

Run the whole study

This calls the API and costs money. The study is capped at 15.00 USD.

$ uv run whichsdk run studies/auth-nextjs.yaml --concurrency 3
5

Count the verdicts

Runs done, failed and pending, the spend so far, and the number of runs with each verdict.

$ uv run whichsdk status studies/auth-nextjs.yaml

Claude Code is the only agent so far. status prints the verdict counts. report writes them as an HTML page and a JSON file.
